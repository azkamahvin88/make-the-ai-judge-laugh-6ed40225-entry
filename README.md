A deterministic Python program that writes one one-line joke about office life — working from home, where the printer can't jam, the coffee is yours, and the boss is a small rectangle you can mute mid-sentence — to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh" bounty.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python standard library only, no network, no randomness) holds one fixed joke string and writes it to `/output/entry.txt`. Two runs produce byte-identical output. See [STUDY.md](STUDY.md) for how the joke was chosen from 19 candidates scored against the judge's five criteria.
